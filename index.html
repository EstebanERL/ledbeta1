⚡ Monorepo · Local-first

TalentForge — Sistema de Contratación

Este repositorio contiene dos proyectos independientes diseñados para ejecutarse en tu máquina local con Node.js y MySQL.

Backend · Express + MySQL

REST API · JWT · Multer · mysql2 (sin Prisma)

cd backend
cp .env.example .env
npm install
npm run db:seed
npm run dev

Frontend · React + Vite

Tailwind · React Router · Axios

cd frontend
cp .env.example .env
npm install
npm run dev

📂 Esquema MySQL listo para MySQL Workbench en backend/sql/schema.sql. Compatible con Aiven.
